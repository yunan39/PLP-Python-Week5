Python Week 5 Assignment
password_generator.py: Generates random passwords of customizable lengths using the `random` and `string` modules.
helpers.py: A custom module providing utility functions (`tables_needed` and `welcome`) with execution guards.
main.py: Imports the `helpers` module to execute and test the custom functions.

Reflection
Working with the `if __name__ == "__main__":` block was the key takeaway here, as it allowed testing `helpers.py` independently without interfering when imported into `main.py`.
